# AIDEN Restaurant Demo v2｜Claude Code Package

## 你可以點用

1. 下載並解壓這個 zip
2. 將整個 folder 放入 Claude Code
3. 先叫 Claude Code 閱讀：
   - `index.html`
   - `PROJECT_STRUCTURE.md`
   - `CLAUDE_OPTIMIZE_PROMPT.md`
4. 貼上 `CLAUDE_OPTIMIZE_PROMPT.md` 入面嘅完整 prompt
5. 叫 Claude Code 優化網站外觀，或轉成 React + Vite

## 檔案說明

- `index.html`：目前完整餐飲網站 Demo v2
- `PROJECT_STRUCTURE.md`：建議網站架構與 React/Vite 拆分方法
- `CLAUDE_OPTIMIZE_PROMPT.md`：可直接 copy 給 Claude Code 的完整優化指令

## 建議第一句對 Claude Code 講

請先閱讀 index.html、PROJECT_STRUCTURE.md、CLAUDE_OPTIMIZE_PROMPT.md，不要立即修改。先用中文總結目前網站功能、設計問題、建議重構方向。之後再開始優化。
